Meu Primeiro Site Pessoal

Este é o meu primeiro site pessoal desenvolvido durante meus estudos. Ele é uma forma de me apresentar e mostrar as minhas habilidades para quem vier visitá-lo

O projeto foi criado para colocar em prática meus conhecimentos iniciais de HTML5 e CSS3, além de servir como um registro da minha evolução no desenvolvimento web.

- Sobre o projeto

O site apresenta algumas informações sobre mim, meus objetivos profissionais, tecnologias que estou estudando e formas de contato.

Durante o desenvolvimento, pratiquei conceitos como:

Estrutura básica do HTML
Tags semânticas
Links internos e externos
Listas
Imagens
Organização de conteúdo com header, nav, main, section e footer
Estilização utilizando CSS
